## Projetos

### [Sistema de Caixa](https://github.com/xande10/projeto01-sistema-caixa)

Aplicação de console desenvolvida em Java para simular operações básicas de um caixa comercial.

O sistema permite:

- Listar produtos e consultar preços.
- Registrar vendas com validação de código e quantidade.
- Atualizar o estoque após cada venda.
- Consultar a quantidade disponível de um produto.
- Visualizar o valor total arrecadado no caixa.

**Conceitos praticados:** arrays, estruturas condicionais e de repetição, `Scanner` e lógica de programação.

**[Ver código do projeto](https://github.com/xande10/projeto01-sistema-caixa)**
