### Projetos

#### [Sistema de Caixa](https://github.com/xande10/projeto01-sistema-caixa)

Aplicação de console desenvolvida em Java para simular operações básicas de um caixa comercial.

**Funcionalidades:**
- Listagem de produtos e preços.
- Registro de vendas com validação de dados.
- Atualização e consulta de estoque.
- Relatório do valor total arrecadado.

**Conceitos utilizados:** arrays, condicionais, estruturas de repetição e entrada de dados com `Scanner`.
